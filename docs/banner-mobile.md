# Banner para celular

Arquivo: `public/brand/hero-mobile-mcell.webp`.
Gerado com a ferramenta integrada imagegen; convertido para WebP de 900 px.

Prompt final: fotografia comercial realista em composição vertical 1024 × 1536, fundo azul-marinho com luz azul suave e espaço negativo na parte superior para o texto HTML. Na parte inferior, smartphone azul, capa transparente, estojo branco de fones sem fio e cabo USB trançado preto, centralizados, com proporções físicas naturais. Sem texto, logotipo, marca-d'água ou bloco de carregador.

O elemento picture seleciona este banner até 640 px. Em telas maiores, mantém o banner existente. Os cards recebem fotos, preços e alvos de toque maiores; no celular, a seção de produtos vem antes das categorias.
